About this report
  • Source: Region I Infrastructure (FMR & Irrigation) Monitoring Form, filtered to Province = Pangasinan and Year Funded ≥ 2024.
  • This is a snapshot, not a live feed — ask Claude to refresh it whenever the source sheet has changed.
  • Obligated/Disbursed figures exclude one row with an obligated amount far exceeding its approved budget (likely a data-entry error in the source sheet) and only count projects with a figure on file.
  • "No status recorded" means the sheet's Physical Status column was left blank for that project — not that work hasn't started.
  • Slippage = Physical Accomplishment % − Financial Accomplishment %, both as reported in the source sheet for each project. A positive value means physical construction progress is ahead of the funds disbursed against it (a billing/disbursement lag); it does not mean the project itself is behind schedule. Projects with slippage over 40 points are flagged high-priority for billing follow-up.
